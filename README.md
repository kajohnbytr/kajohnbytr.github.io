# John Aaron Junio — Portfolio

A responsive personal portfolio showcasing my cybersecurity background, software projects, technical skills, professional certificates, and contact information.

## Live portfolio

Visit the portfolio at **[https://kajohnbytr.github.io](https://kajohnbytr.github.io)**.

## Built with

- React
- Vite
- JavaScript and JSX
- CSS and Tailwind CSS
- React Bits animated components
- GitHub Pages

## Local development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
